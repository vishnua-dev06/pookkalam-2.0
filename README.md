# POOVUM CODEUM 🌸

**Design it. Code it. Bloom it.**

An interactive, responsive digital Pookkalam design studio and pattern creator for creating, previewing, and exporting traditional Onam floral carpets and outline layout diagrams.

---

## Features

- **Sector Studio**: Design intricate botanical slices that repeat with customizable rotational symmetry.
- **Drawing Tools & Shapes**: Pen, lines, curves, circles, and draggable geometric floral petal palettes.
- **Pookkalam Preview**: Real-time mandala rendering with zoom, pan, and magnifier inspection.
- **Export & Layout**: Download full-color botanical Pookkalam PNGs and printable outline layout diagrams.
- **Designs Gallery**: Explore and download community and curated Pookkalam designs.
